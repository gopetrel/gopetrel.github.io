Design & DFM

Most of the cost of a machined part is fixed before a machine is switched on. These notes are about the drawing - how to set tolerances, where a corner radius matters, and which checks catch a problem while it is still free to fix. 3 articles.

What this topic covers

  • Tolerance strategy - Where a tight tolerance earns its money, and where it only adds cost - plus how to size a stack-up before release.
  • Geometry rules - Corner radii, pocket depth, wall thickness and the features that force a part into a slower, more expensive process.
  • Drawing quality - Datums, revision control and the four things that must be on a drawing before it can be quoted unambiguously.
  • Commercial impact - Which design decisions change the price class of a part, and which only change it by a few per cent.
